# GAM Analytics V0.7.2 Foundation

Base limpa construída sobre a V0.7.1 funcional.

## Correções
- Criação e edição de integrantes usam operações separadas.
- Matrícula duplicada recebe mensagem específica.
- Erros do Supabase preservam a causa real.
- Aviso de migração só aparece quando faltam campos de identidade.
- Upload e remoção de fotos continuam restritos ao administrador.

## Validação
Execute `npm ci`, `npm run lint`, `npm run check` e `npm run build`.
